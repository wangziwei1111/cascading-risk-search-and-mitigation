# RL Extra Diagnostics

These artifacts are useful for explaining PPO behavior, but they are not part of the original paper method:

- action value scan
- one-step oracle
- oracle behavior cloning
- safe oracle gate
- GCN-selected high-risk scenario bridge

Use this boundary in reports:

- `results/rl_mitigation/paper/`: main paper reproduction.
- `results/rl_mitigation/ieee14/diagnostics/`: PPO/action diagnostics and oracle upper-bound analysis.
- `results/rl_mitigation/ieee14/enhanced_experiments/`: oracle BC, safe gate, and GCN-RL bridge style analyses.

Do not describe oracle BC or safe gate as the paper PPO method.
